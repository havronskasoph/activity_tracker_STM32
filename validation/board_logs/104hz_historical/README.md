# Логи з плати: варіант 104 Гц (історичні)

Ці логи зняті 17 листопада 2026 з прошивки, яка несла модель
`st_ign_var2_104hz`. Саме вони дали вимірювання, що фактичний ODR датчика на
5.6 % вищий за номінал: замовлені 104 Гц давали 109.8, і вікно з 208 відліків
тривало 1.89 с замість 2.00.

Це вимірювання й стало підставою перейти на модель 27.45 Гц, навчену під
фактичну частоту плати при ODR 26.

| файл | що в ньому |
|---|---|
| `stream_debug.log` | потік CSV + передбачення, Debug-збірка |
| `selftest_debug.log` | самотест 50 векторів, Debug (-O0): 50/50, 120.9 мс |
| `selftest_release.log` | самотест, Release (-Os): 50/50, 34.7 мс |
| `operating_release.log` | робочий режим без CSV |

Для поточної прошивки (27.45 Гц) ці числа **не діють** — її треба заміряти
наново на платі.
